# 배포 체크리스트 (10/28 마감)

> 배포 스크립트: `scripts/deployment.sh` (도커 이미지 빌드·푸시 → EC2 에 compose·nginx 설정 복사 → 실행 → DB 마이그레이션)

## 0. 준비물 (팀에서 받기)

- [ ] EC2 IP · SSH 키 파일(`~/.ssh/<키>.pem`) · (https 쓰면) 도메인
- [ ] Docker Hub 계정·토큰 (이미지 올릴 곳)
- [ ] 팀 OpenAI 키 (**채팅·코드·스크린샷에 붙이지 않는다. `envs/.prod.env` 에만**)

## 1. `envs/.prod.env` 만들기

`envs/example.prod.env` 를 복사해서 값만 채운다. 이 파일은 `.gitignore` 라 레포에 안 올라간다.

- [ ] ⚠ **`SECRET_KEY` 를 반드시 새 값으로.** 예시 파일의 값은 공개 레포에 올라가 있어서, 그대로 쓰면 누구나 로그인 토큰을 위조할 수 있다.
  새 값 만들기: `python3 -c "import secrets; print(secrets.token_urlsafe(48))"`
  (챗봇은 compose 가 이 값을 `LOGIN_SECRET_KEY` 로 넘겨서 같은 토큰을 쓴다)
- [ ] `DB_PASSWORD` · `DB_ROOT_PASSWORD` 도 예시 값이 아닌 새 값
- [ ] `OPENAI_API_KEY` = 팀 키
- [ ] `APP_VERSION` · `AI_WORKER_VERSION` · `CHATBOT_VERSION` = 이번에 올릴 버전 (예: v1.0.0)
- [ ] AI 모드 결정 (아래 3번)

## 2. 실행

```bash
./scripts/deployment.sh
# 선택: 1 3   (fastapi + chatbot. ai_worker 는 아직 실제 작업 없음)
```

- 처음 배포라면 EC2 에서 한 번 `cd ~/project && docker compose up -d` 로 mysql·redis·nginx 까지 전부 띄운다 (스크립트는 고른 서비스만 바꿈)
- fastapi 를 배포하면 스크립트가 `aerich upgrade` 로 새 테이블을 만든다 (진료기록·가이드·OCR·가입 칼럼·피드백 = 마이그레이션 3~7)
- https 는 `scripts/certbot.sh` 로 인증서를 먼저 받는다

## 3. AI 모드 — 팀 결정 필요 ⚠

| 설정 | 데모용 (권장) | 엄격 (원칙대로) |
|---|---|---|
| `GUIDE_LLM_MODE` / `OCR_MODE` / `CHAT_LLM_MODE` | `openai` | `openai` |
| `GUIDE_ALLOW_UNREVIEWED_DOCS` / `CHAT_ALLOW_UNREVIEWED_DOCS` | `true` | `false` |
| `CHAT_APP_ENV` | `dev` | `prod` |
| 결과 | 감수 전 안내문도 근거로 씀 → 데모 시나리오가 다 동작 | 멘토 감수 전에는 가이드 '자료 없음', 챗봇 '안내문 없음' 만 나옴 |

멘토 감수(`reviewed: true`)가 끝난 안내문이 생기면 엄격 모드로 바꾼다. 화면에는 출처·면책 문구가 항상 붙는다.

## 4. 배포 직후 확인 (5분)

- [ ] `https://<도메인>/` → 첫 화면(언어 선택)
- [ ] `https://<도메인>/api/docs` → Swagger
- [ ] `https://<도메인>/api/v1/chat/langs` → 언어 4개 (nginx → 챗봇 연결 확인)
- [ ] 중국어로 가입(전화번호 없이) → 로그인 → 처방전 사진 → 가이드 → 챗봇 질문(글자가 흘러나오는지) → 응급 질문("打完玻尿酸后视力模糊")에 빨간 카드
- [ ] P95 측정: `BASE_URL=https://<도메인> DEMO_PASSWORD='…' uv run python scripts/perf/measure_p95.py --n 30`
  (openai 모드면 측정 횟수만큼 비용 → `--n 10` 정도로)
- [ ] 결과를 `scripts/perf/README.md` 표에 반영
