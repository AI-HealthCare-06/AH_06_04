# 안내문 넣는 법 (`chatbot/data/docs/`)

챗봇은 **이 폴더의 안내문 안에서만** 답합니다. 안내문 하나 = `.md` 파일 하나이고, 코드를 고칠 필요는 없습니다.

## 형식

```
---
id: chemical-peel                     ← 영문 소문자·하이픈, 파일 이름과 같게 (chemical-peel.md)
title_ko: 필링 후 관리                  ← 필수
title_en: Care after chemical peel     ← 필수
title_ja: ピーリング後のケア              ← 있으면 일본어 화면에서 이 제목
title_zh-Hans: 化学换肤后的护理           ← 있으면 중국어 화면에서 이 제목
keywords: 필링, peel, ピーリング, 换肤     ← 쉼표로. 4개 언어로 많이
source: 출처 (예: ○○병원 시술 안내문 2026-10)
reviewed: false                       ← 멘토·의료진 감수가 끝나면 true
---
## ko
본문 3~6문장

## en
본문 3~6문장

## ja
(있으면) 본문

## zh-Hans
(있으면) 본문
```

- `## ko` · `## en` 본문은 꼭 있어야 합니다. `ja` · `zh-Hans` 본문이 없으면 그 언어 질문에 영어 본문이 근거로 들어갑니다.
- **`reviewed: false` 인 안내문은 기본 설정에서 검색되지 않습니다.** 감수가 끝난 뒤 `true` 로 바꾸세요.
  데모·개발 때만 `.env` 의 `ALLOW_UNREVIEWED_DOCS=true` 로 감수 전 안내문을 포함할 수 있습니다 (`APP_ENV=prod` 에서는 금지).

## keywords 규칙

- 찾기는 **낱말 맞추기**입니다. 질문에 keywords 가 하나라도 들어 있어야 그 안내문을 찾습니다.
- 한국어 낱말은 **낱말의 시작**에서만 맞춥니다. 그래서 `약을` 은 "약을 깜빡했어요" 에는 맞지만 "예약을 바꿀래요" 에는 맞지 않고,
  `술` 은 "술 마셔도 돼요?" 에는 맞지만 "시술 후" 에는 맞지 않습니다.
- 영어 낱말도 낱말의 시작에서만 맞춥니다 (`wash` → washing 은 맞음, `sun` → sunday 는 안 맞음).
- 중국어·일본어는 띄어쓰기가 없어 글자 그대로 맞춥니다.

## 쓰면 안 되는 문장

본문에 약 용량·복용 횟수 지시(예: "이 약을 하루 두 번 드세요", "500 mg")가 있으면 답 검사 필터에 걸립니다.
테스트(`uv run pytest -q`)가 모든 안내문 본문을 필터에 넣어 보고, 걸리는 문장이 있으면 알려 줍니다.
"세안은 하루 두 번", "보습제를 하루 2회" 처럼 약과 무관한 생활관리 문장은 괜찮습니다.

## 넣은 뒤

1. `uv run pytest -q` — 형식 · 필터 확인
2. `uv run python scripts/eval.py` — 점수표 확인. 그 안내문에 맞는 질문을 `eval/golden.jsonl` 에 한 줄씩 더하면 좋습니다
3. 서버를 다시 켜면 반영
